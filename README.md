# MZ Crayon Illustrations

A review-first agent Skill for turning one clear knowledge judgment into an original 16:9 Muzi crayon illustration.

![Muzi action library](mz-crayon-illustrations/assets/identity/muzi-crayon-action-index.png)

## What it preserves

- A stable Muzi narrator identity and optional Ragdoll companion.
- Strong wax-crayon texture, warm-white space, deep-navy outlines, mustard blocks, and restrained annotations.
- One judgment, one physical metaphor, one readable story flow.
- Source fidelity: labels and named facts come only from user-provided content.

The Skill selects one of sixteen semantic actions when it genuinely fits, or uses a controlled free-pose mode for comparisons, environments, sequences, and complex interactions. It validates a structured review record and stops at `READY_FOR_REVIEW`.

## Install

```text
$skill-installer install https://github.com/MuziGeek/mz-crayon-illustrations/tree/v1.0.0/mz-crayon-illustrations
```

For the current main branch:

```text
$skill-installer install https://github.com/MuziGeek/mz-crayon-illustrations/tree/main/mz-crayon-illustrations
```

## Try it

```text
Use $mz-crayon-illustrations to turn this article's main judgment into one 16:9 knowledge illustration.
Use $mz-crayon-illustrations to show why collecting information is not the same as retrieving it.
```

## Review boundary

The Skill never uploads, publishes, replaces account assets, invents factual labels, or claims acceptance. Generation and local QA are separate from external release.
